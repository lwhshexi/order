# 点餐网页

一个用 HTML、CSS、JavaScript 写的简易点餐页面，全程在手机上完成。

在线体验：https://lwhshexi.github.io/order/orderapp/

## 功能

- 菜品分类、搜索
- 加减菜品，自动计算合计
- 填写桌号和备注，提交订单
- 查看历史订单，切换订单状态，删除或清空订单
- 点击菜品图片放大

## 技术

- 原生 HTML / CSS / JavaScript
- 订单数据保存在浏览器 localStorage（只存在本机）
- 使用 GitHub Pages 发布

## 说明

这是练手项目，没有后端，朋友下的订单只在他自己的手机里。
